SHARED CONTEXT

너와 에이전트가 같은 두 지도를 본다.

예시 기능: 항목을 저장하고 다시 조회한다 · 아래는 계획 구조의 설명이며 실제 과제 구현 결과가 아니다.

너 · 전체 맥락 유지HTML에서 책임과 현재 위치를 읽는다.
같은 과제 ID · 같은 지도 버전인수 기준 + 두 지도 + 테스트 경계 + E2E 경로
에이전트 · 현재 과제 구현같은 지도 원본과 코드 근거를 읽는다.

전체 지도에서 변경 부분을 갱신한다. HTML과 지도 원본은 에이전트가 함께 갱신하며, 자동 동기화 서비스는 아니다.

COMPOSABLE SKILLS

상위 스킬은 흐름을, 도구 스킬은 결과를 맡는다.

상위 스킬 읽기 ↗지도 도구 읽기 ↗근거 도구 읽기 ↗공개 스킬·호출 관계 ↗
실제로 사용할 파일과 시작 문장

설치한 프로젝트에서는 AGENTS.snippet.md의 연결 문구로 위 스킬을 사용할 수 있다. “이 과제를 우리 워크플로우로 분해하고, 첫 서브 과제와 두 지도부터 보여줘”라고 시작하면 된다.

.workflow/과제명/
  plan.md                 전체 작업과 의존관계
  tasks/T01.md            현재 과제 · 기준 · 상태
  maps/                   객체 원본 · 흐름 원본 · HTML
  evidence/T01/           구현 인계 · 공동 E2E · 실행 근거

서브 과제 양식 · 공유 계약과 상태 전이

코딩 에이전트가 읽고 실행하는 절차형 스킬이다. 현재 세션의 전역 명령 등록이나 별도 실행 서버는 만들지 않았다.

AFTER THE WHOLE TASK

별도 연습 요청 시 사용할 훈련 흐름이다. 현재 task-delivery의 자동 후속 호출에는 연결되어 있지 않다.

프롬프트 전달과 판단은 과제·합의·검증 기록에서 살펴본다. 현재 별도의 자동 프롬프트 채점 스킬은 없다. 설계 이유와 훈련 범위 읽기 ↗
